工作人員小卡

印出來護貝，每個崗位發自己那一段。一個狀況一行，照順序按。
反引號裡的字（例如 開始對戰）就是畫面上那顆按鈕的字，找不到就是版本不對，問主辦。
為什麼要這樣做、每一頁的截圖，看 操作手冊.html。指令看 README.md。
產生可列印版：python docs/md2html.py 工作人員小卡.md。

桌邊裁判（裁判回報頁，用裁判 PIN）

狀況怎麼按
雙方就位、陀螺檢查完開始對戰（計時從這一刻算）
打完了（一般桌）點勝方 → 選比分 → 送出
逐分計分（16 強各桌；資格賽要逐分記的桌先按 改用逐分計分板）每打完一招就按對應的得分方式。先到 4 分畫面會自己跳到確認
…畫面寫「兩下按太快，第二下沒有算」手指彈到、同一顆鈕連按兩下，系統只算一下（防止一招被記兩次）。真的要再加就再按一次
…按錯一分復原上一分
…要整場重來歸零
…其實還沒開打就按了開始退回準備
未到、棄權、失格最下面「直接判定勝方」→ 照賽前簡報統一的記法（建議一律 不記比分，直接送出）
送錯成績右上 我的回報 → 改或取消。後面受影響的賽程系統會自己重算
選手說名字顯示錯了選手名字旁邊的 暱稱 → 改
要去顧別桌右上 換桌
開始鈕變灰、寫「賽事暫停中 請稍等」主辦暫停了開賽，不是你的手機壞掉。手上這場照樣打完、照樣送得出去，等主辦恢復後按鈕會自己亮
手機沒電、當掉叫場控：他在看板上可以直接幫你判
PIN 一直說錯、被鎖住先確認 PIN 有沒有打對（多半是打錯）。真的鎖住就找主辦解

唱名（多桌裁判頁 → 上面切到「唱名」）

狀況怎麼按
叫下一場由上往下念。左邊橘色大數字是桌號。念完按 已唱名，卡片變灰
選手上桌開打了不用按，卡片會自己消失
怕漏掉新的右下打開 提示音
一個人顧好幾桌也要回報上面切到「回報」，每桌一張卡，直接 開始對戰 或點勝方。開始按錯點右邊 ↺

場控（牌桌調度看板，不用 PIN）

狀況怎麼按
看哪裡還沒打上面的「空桌／待戰／已完成」三個數字；右邊「待戰隊列」就是唱名順序
選手已就位、裁判還沒按開始卡片右下 ▶ 開始 代按
裁判手機掛了，要代判點那一桌的選手名字 → ▸ 判定勝 → 輸入裁判 PIN → 選比分
桌子是灰色的 暫停使用主辦停用了那張桌，不是系統卡住。要恢復找主辦
確認剛剛那場有沒有回報進來右下「已完成」清單
主辦問「這一區還剩幾場」看板右上「還剩」那一格（含還沒確定對手的後面幾輪）

報到櫃台（報到櫃台頁，用 PIN）

狀況怎麼按
選手秀 QR用手機相機掃，會自己開到這一頁並帶出他的資料
選手念 6 碼代碼打進上面那格 → 查詢
沒帶手機、代碼弄丟下面「直接搜尋」打姓名或電話末四碼
核對證件對卡片上的姓名和身分證後四碼 → 核對無誤，確認報到。同一支電話的小孩會一起列出來
標籤是橘色或紅色名單對不上，看證件人工判斷
按錯人那個人的按鈕會變成 取消報到
選手端說「請直接到櫃台」主辦已經停止收件，照常在櫃台幫他處理

檢錄台（檢錄審核頁，用 PIN）

狀況怎麼按
🟢 名單相符直接 通過
🟠 名單查無此人看底下列出的相近姓名，對照證件決定。也可以用那一筆底下的搜尋框打姓名、電話或證件末四碼 → 查 → 點對的那一列就綁好了
🔴 尚未報到請他先去報到台，或當面確認後再通過（系統不會擋，判斷在你）
賽區不對底下會寫他登記在哪一區，請他去對的檢錄台
資料要先改再通過左邊鉛筆 → 改完再通過
判錯了已判過的那筆按 改判
找不到某位選手那一筆掃他的報到 QR，會直接跳到他那一列

主辦（主辦控制台，用主辦 PIN）

狀況怎麼按
開賽賽事狀態按 進行中（同時會自動停止收件）
午休、頒獎、等器材按 暫停中（全場計時一起停）。回來按 進行中
不要有人偷跑開下一場開賽開關 → 暫停開賽（裁判不能開新的一場）。打到一半的照樣能送。要恢復按 恢復開賽
要讓大家知道幾點恢復附註訊息打「預計 14:30 恢復比賽」
重新讓選手自己報到／檢錄重新開放收件（關掉是 停止收件（關閉選手端頁面））
資格賽臨時加一位選手「現場加入選手（資格賽）」選區、號碼、暱稱 → 加入。只能加在輪空位置，抽 16 強之後就不能加了
16 強要一場一場打決賽牌桌 → 1 桌。要恢復正常記得按回 4 桌
指定某一場放到某一桌候補清單裡那一場的「放 N 桌」
小組同分，主辦裁定了名次決賽名次裁定 → 手動排名次 → 排好 → 送出這組名次
某台螢幕卡住強制所有畫面重整（最多 15 秒，按一次就好）
有人被鎖住PIN 鎖定 → 立即解鎖（主辦自己被鎖也能在同一台解）
申訴、改別人的成績開裁判回報頁用主辦 PIN 登入 → 全部回報紀錄 → 搜尋場次或名字 → 取消／修改。視窗變紅就停下來想：取消任何一場資格賽，16 強分組會整個退回
查是誰改了什麼最下面「操作紀錄」
比賽結束按 已結束。確認備份資料夾裡有最新的 reports.json 才收機器

每一階段開始前印一份紙本（紙本列印頁）：資格賽開打前印「資格賽對戰表」，16 強抽完籤印「16 強分組表」和 16 強的「結果單」。放在主辦桌，系統出事就直接拿出來。

出事的時候

狀況怎麼辦
主控台最上面「系統健康」出現紅字照紅字說的處理。「畫面資料超過 30 秒沒更新」＝全場螢幕凍住了；「成績可能沒有存進硬碟」要立刻處理
大腦的黑色視窗被關掉、電腦重開用一模一樣的指令重開，成績會自己接回來。絕對不要加 --fresh
網路斷了、系統整個不能用拿出事先印好的紙本：對戰表照著叫號，每一桌發一張結果單，裁判在得分格記每一招、寫總分、勾勝方
…系統恢復之後系統會把還沒結果的場次照常排上桌。場控在牌桌調度看板找到結果單上那一場 → ▸ 判定勝 補登；判完下一場會自己補上桌，照著繼續。補完一張就勾「已輸入系統」，才知道哪幾張還沒補。照輪次順序補（第 1 輪補完才會出現第 2 輪）
…要補的場次很多主辦用 results.csv 一次補（開機要加 --results results.csv），做法見操作手冊「一次補很多場」。補完一定要到看板確認，打錯的那一行會被靜靜跳過
…要查某一場的紀錄結果單上的「系統編號」（例如 A-R0-M05）就是「全部回報紀錄」搜尋框要打的場次代號
…沒有事先印大腦還開得起來就先開紙本列印頁印；連不上大腦的話，頁面會說「連不上大腦」而且不給印 —— 它不會印出假資料
家長說觀眾頁變灰、底下寫「連不上賽務系統」他的手機連不上，畫面上是舊資料（會寫幾點的）。請他換網路（Wi-Fi／4G 切換）或等一下，連上會自己恢復，不用重整
紙本跟螢幕對不起來看紙上右上角的「資料時間」，以比較新的那一份為準
不小心開了兩隻大腦第二隻會自己拒絕並印出說明，照著做。絕不要讓兩隻一起跑
開機時一堆 !!!! 警告紀錄檔讀不起來，立刻 Ctrl+C，照操作手冊「換一台電腦繼續比賽」第 3 步
筆電整台掛了照操作手冊「換一台電腦繼續比賽」，有備份十分鐘內做得完

賽前演練（每個崗位 15 分鐘）

沒親手按過，現場一定會慌。 2026-08-01 那場 16 強改紙本，就是因為裁判頁在手機上捲不到確認鈕 —— 那種事只有真的拿手機按過才會發現。

  1. 另外複製一份資料夾（例如 C:\zanmen-演練），在那一份裡開大腦，不要在正式資料夾裡演練（演練的成績留在正式資料夾，當天就得記得加 --fresh，加錯就清掉整場）。
  2. 在演練資料夾開：python brain.py --participants participants.csv --judges judges.csv --fresh，大家的手機連同一個網路。
  3. 每個人用自己當天要用的那支手機，至少做一次：
  4. 桌邊裁判：開始對戰 → 送一場成績 → 從「我的回報」取消它 → 再送一次；直播桌逐分計分、復原上一分
  5. 唱名：唱一輪、打開提示音
  6. 場控：代按開始、代判一場
  7. 報到／檢錄：掃一張 QR、通過一筆、改判一筆
  8. 主辦：暫停中／進行中、暫停開賽再恢復、強制重整、印一份紙本
  9. 要練 16 強：關掉大腦，改用 python brain.py --participants participants.csv --judges judges.csv --fresh --ff --autodraw（資格賽自動打完、自動抽籤），練小組賽、名次賽和紙本的 16 強分組表。
  10. 演練完把 C:\zanmen-演練 整個刪掉。
